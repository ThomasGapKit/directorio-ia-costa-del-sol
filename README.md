# IA Costa — directorio-ia-costa-del-sol

Directorio estático (HTML/CSS, sin build) para negocios de la Costa del Sol.

## Placeholders para cambiar
- **Stripe**: en `index.html`, `id="stripe-link"` con `href="#stripe-pendiente"`. Sustituir por el Payment Link de Stripe.
- **Checklist / lead magnet**: `id="newsletter-link"` apunta a Payhip (`https://payhip.com/b/oQKOg`); Payhip recoge el email al descargar.
- **Curso Payhip**: `id="payhip-link"` apunta a `https://payhip.com/b/Ec5Tw` (€19).
